# 격파왕 게임 개발 기획서

## 1. 게임 개요

- **게임명:** 격파왕
- **게임 장르:** 캐주얼 클릭 액션 게임
- **개발 언어:** C#
- **개발 환경:** Visual Studio 2022 (Windows Forms)
- **게임 목표:** 제한 시간 안에 정해진 횟수 이상 격파대상을 클릭하여 격파에 성공하고, 최대한 높은 단계까지 도달하는 게임

## 2. 게임 기획 의도

마우스 클릭을 이용하여 누구나 쉽게 즐길 수 있는 간단한 격파 게임을 제작한다.

단계가 올라갈수록 제한 시간은 짧아지고 필요한 클릭 횟수는 증가하도록 하여 난이도를 높이고, 플레이어가 자신의 기록에 도전할 수 있도록 한다.

## 3. 게임 진행 방식

1. 게임 시작 버튼을 누르면 1단계가 시작된다.
2. 화면 중앙에 격파대상이 나타난다.
3. 플레이어는 제한 시간 안에 격파대상을 목표 횟수 이상 클릭해야 한다.
4. 목표 클릭 횟수를 달성하면 격파대상이 격파되고 다음 단계로 넘어간다.
5. 다음 단계에서는 제한 시간이 줄어들고 목표 클릭 횟수가 증가한다.
6. 제한 시간 안에 목표를 달성하지 못하면 게임이 종료된다.

## 4. 단계별 난이도

| 단계 | 제한 시간 | 목표 클릭 횟수 |
|---|---:|---:|
| 1단계 | 10초 | 10회 |
| 2단계 | 9초 | 15회 |
| 3단계 | 8초 | 20회 |
| 4단계 | 7초 | 25회 |
| 5단계 | 6초 | 30회 |

5단계 이후에도 단계가 올라갈 때마다 목표 클릭 횟수는 5회씩 증가하며, 제한 시간은 최소 3초까지 감소한다.

## 5. 주요 기능

- **게임 시작:** 시작 버튼을 누르면 게임 진행
- **클릭 횟수 측정:** 격파대상을 클릭할 때마다 클릭 횟수 증가
- **제한 시간:** 타이머를 이용하여 남은 시간 표시
- **격파 성공:** 목표 클릭 횟수 달성 시 격파 성공 메시지 출력
- **난이도 증가:** 단계별 제한 시간 감소 및 목표 클릭 횟수 증가
- **점수 표시:** 격파 성공에 따른 점수 표시
- **게임 종료:** 제한 시간 초과 시 게임 오버
- **다시하기:** 게임 종료 후 1단계부터 재도전 가능

## 6. 게임 화면 구성

게임 화면 상단에는 게임 제목인 **격파왕**을 표시한다. 현재 단계, 남은 시간, 현재 클릭 횟수, 목표 클릭 횟수 및 점수를 확인할 수 있도록 구성한다.

화면 중앙에는 클릭할 수 있는 격파대상을 배치하고, 아래에는 **시작** 및 **다시하기** 버튼을 배치한다. 격파 성공 시 격파대상이 깨지는 연출을 표시한다.

## 7. 필요한 리소스

| 리소스 | 수량 | 용도 |
|---|---:|---|
| 격파대상 | 3개 | 게임에서 클릭하여 격파하는 대상 이미지 3종 |
| 제목 | 1개 | '격파왕' 타이틀 표시 |
| 시작 | 1개 | 게임 시작 버튼 |
| 다시하기 | 1개 | 게임 재시작 버튼 |
| 점수 | 1개 | 현재 점수 표시용 UI |

※ 이미지 리소스는 PNG 형식으로 준비하고, 점수 숫자 및 시간·단계 정보는 C# UI 텍스트로 표시할 수 있다.

## 8. 기대 효과

간단한 마우스 조작만으로 즐길 수 있으며, 단계가 올라갈수록 난이도가 증가하여 도전 욕구를 유발할 수 있다.

또한 C#의 클릭 이벤트, 타이머, 조건문 등을 활용하여 프로그래밍의 기본 기능을 학습하고 응용할 수 있다.
